# Dashboard Screenshots

This folder contains screenshots of the Power BI dashboard for the RFM Customer Segmentation project.

| File | Description |
|------|-------------|
| `overview.png` | Dashboard overview: total customers, revenue, and key KPIs |
| `rfm_segments.png` | Customer distribution across RFM segments (Champions, Loyal, At Risk, etc.) |
| `segment_revenue.png` | Revenue contribution by segment |
| `customer_details.png` | Customer-level view with Recency, Frequency, and Monetary scores |

## Notes
- Screenshots are taken from `dashboard/dashboard.pbix`.
- Open the .pbix file in Power BI Desktop to explore the interactive version.
